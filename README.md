# Your ML / AI Tutor: Advanced

The first course took you from a blank Python file to shipping a model. This one starts where that one ended: you already know how to train, evaluate and serve something that works, and now we will build the judgement around it. Over fifty weekday lessons we will work through uncertainty and causal inference, time series and recommenders, graphs, transformers written from scratch, efficient training, reinforcement learning, and the insides of large language models — tokenisers, sampling, the KV cache, parameter-efficient fine-tuning, careful agents, and retrieval you can actually evaluate. Everything is in Python, everything is meant to run on a laptop CPU, and we still publish two short lessons every weekday.

The point is not to collect techniques. It is to leave you able to ask better questions of data and of models: how sure are we, what caused what, what would break in production, and whether a more complicated system is worth it. Each lesson is a small, complete step with a readable script and a few exercises, taught in strict order, with a capstone at the end that you scope, build and ship yourself. If you have finished the first course, or you already have that grounding, this is the next stretch of the road.
